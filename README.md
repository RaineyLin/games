# 迷你甜食防禦軍

本機 2D 塔防原型。玩家用油量自由擺放砲塔與阻擋牆，進攻中也能追加建造來阻止工蟻搬走甜食。

## 執行

```bash
python3 -m pip install -r requirements.txt
python3 -m mini_sweet_defense.main
```

## 操作

- `1`：選擇基礎砲塔
- `2`：選擇阻擋牆
- 上方建造按鈕或 `1` / `2`：切換放置物品
- 左鍵：建造，準備與進攻階段皆可
- `Space`：開始波段
- `F1` / `F2` / `F3`：開發階段切換關卡
- `R`：勝利或失敗後重新開始
- `Esc`：離開

## 已實作重點

- JSON 資料驅動：`data/` 內可調整場地、螞蟻、甜食、砲塔、阻擋物與關卡。
- 支援多關卡資料，開發階段可用 `F1` / `F2` / `F3` 快速切換。
- 自由 `x,y` 擺放與移動，內部使用隱形導航格 A* 尋路。
- 上方資訊列提供建造按鈕，顯示可放置物、依油量換算的可放置數量與成本。
- 工蟻只搬甜食，不拆建築。
- 若工蟻路徑被封死，會觸發巨大兵蟻拆除阻礙，打通後離開。
- 第三關支援正式波次兵蟻；兵蟻會破壞關卡設定數量的可破壞建築後離開。
- 第二關支援兵蟻不可破壞的隨機障礙物。
- 進攻中放置阻擋移動的建築後，場上移動中的螞蟻會重新尋路。
- 甜食被搬走後會依剩餘數量縮小；砲塔範圍只在放置預覽或滑鼠 hover 時顯示。
- 甜食支援立即拿取與啃咬後搬運兩種模式。
- 油量只作建造成本，擊殺螞蟻可回收油量；分數獨立計算。
- 開發階段預設遊玩速度為 3 倍，可在 `data/game_config.json` 的 `gameplay.timeScale` 調整。
